# 日常规划 3.0

一个运行在 Windows 本机的个人日程规划系统：支持多个本地账号、每日任务与自动排程、习惯打卡与统计、专注计时、周复盘和总览仪表盘。数据全部保存在本机 SQLite，不依赖任何云端服务。

## 功能

- 多账号：支持用户名+密码账号，也支持免密本地档案；可随时创建和切换账号，数据互相隔离
- 每日任务：标题、日期、优先级、分类、备注、开始时间、时长，自动按优先级排序
- 清空待办：一键清空当天或所有未完成的任务
- 自动排程：识别“30分钟、1小时、5公里”等描述；支持自定义排程时段和午休；P1 优先、长任务优先，自动避开已锁定时间
- 时间轴拖拽：拖动任务条修改开始时间，拖底部手柄修改时长
- 习惯打卡：每日打卡、连续天数、最长连续、月度热力图和统计
- 专注计时：25/45 分钟或自定义时长，可关联任务并记录专注记录
- 周复盘：按年份+周保存每周总结，并展示本周任务、习惯、专注概况
- 日/年度复盘：记录每日总结和年度回顾，并管理每年目标
- 月历可视化：按月查看每天的任务完成、习惯打卡和专注时长，点击某天直接进入当日日程
- 总览仪表盘：今日完成率、近 7 天趋势、习惯热力图、接下来的任务、今日/本周专注
- 主题颜色：6 套预设色或自定义主色，每个账号独立保存
- 数据备份：导出/导入全部任务、规则、习惯、专注记录和复盘

## 快速开始

1. 双击 `启动.bat`（首次会自动安装依赖并打开浏览器）。
2. 在登录页注册一个账号，或直接进入免密“默认用户”。
3. 在“今日”页添加任务并点击“自动排程”。
4. 到“习惯”“专注”“复盘”页记录日常，到“总览”页查看统计。

手动启动：

```bat
npm install
npm start
```

运行测试：

```bat
npm test
```

## iPhone 访问

1. 手机和 Windows 连接同一个 Wi-Fi。
2. 启动服务后，终端会打印 `http://192.168.x.x:3000` 形式的地址。
3. 在 iPhone 的 Safari 打开该地址。
4. 点分享按钮，选择“添加到主屏幕”，之后可像 App 一样打开。

如果手机打不开，放行 Windows 防火墙（以管理员身份运行 PowerShell 或 CMD）：

```bat
netsh advfirewall firewall add rule name="Daily Planner" dir=in action=allow protocol=TCP localport=3000
```

## 多账号说明

- 账号只保存在本机 SQLite，不做云端注册或找回密码。
- 注册时密码留空会创建免密档案；免密档案在登录页点击即可进入。
- 忘记密码时，需要在本机数据目录中手动重置。
- 每个账号的任务、规则、习惯、专注记录、复盘和主题设置互相隔离。
- 首次升级时，旧数据会自动迁移到免密“默认用户”，不会被删除。

## 自动排程规则

默认规则示例：

| 关键词 | 时长 | 时段 |
| --- | --- | --- |
| 会议 / 开会 | 60 分钟 | 上午 |
| 写作 / 报告 / 方案 / 文档 | 60-90 分钟 | 上午 |
| 学习 / 阅读 / 课程 | 60 分钟 | 下午 |
| 电话 | 20 分钟 | 下午 |
| 健身 / 跑步 / 运动 / 瑜伽 | 45 分钟 | 晚上 |
| 买菜 / 购物 / 家务 | 30 分钟 | 晚上 |

标题中出现“30分钟、1小时、5公里、50页、30题、1章”等数量词时优先按数量词估算；未匹配时按分类兜底。排程默认 09:00-22:00，午休 12:00-13:30 不会安排普通任务；P1 优先上午、P2 优先下午、P3 优先晚上，任务会分散放入不同空闲时段，不会全部挤在同一个时间点；可在设置页修改。

## 目录结构

```text
lib/db.js           数据层：账号、任务、习惯、专注、复盘、统计
lib/scheduler.js    自动排程与时长解析
server.js           Express API 与认证
public/             前端页面（原生 JS + CSS + PWA）
tests/              Node 内置 test runner 测试
data/               运行时生成的 SQLite 数据库
```

## 安全说明

- 数据只保存在本机，不依赖云端服务。
- 密码使用 Node 内置 `crypto.scrypt` 哈希后存储。
- 本应用是局域网/私有网络应用，不建议直接暴露到公网。
