# Daily Planner · 日常规划

一个运行在本机的个人日程规划系统：多账号、每日任务与自动排程、习惯打卡、专注计时、日/周/年度复盘、年度目标和月历可视化。数据全部保存在本机 SQLite，不依赖任何云端服务。

## 功能

- 多账号：支持用户名+密码账号和免密本地档案，数据互相隔离
- 每日任务：优先级、分类、时间、时长、备注，自动排序与清空待办
- 自动排程：识别“30分钟、1小时、5公里、50页、30题”等描述，按优先级分散到不同时段
- 时间轴拖拽：拖动任务条改时间，拖底部手柄改时长
- 习惯打卡：连续天数、最长连续、月度热力图与统计
- 专注计时：25/45 分钟或自定义时长，可关联任务
- 复盘与目标：日复盘、周复盘、年度复盘、年度目标
- 月历可视化：查看每天任务、习惯、专注记录，点击日期进入当天
- 主题颜色：6 套预设色或自定义主色
- 数据备份：导出/导入全部个人数据

## 快速开始

环境要求：Node.js 20 或更高版本。

```bash
npm install
npm start
```

然后打开 http://localhost:3000 ，在登录页注册一个账号即可使用。

Windows 用户也可以直接双击 `启动.bat`，它会自动安装依赖并打开浏览器。

## 局域网访问（可选）

如果希望在同一网络下的其他设备（例如手机）访问：

1. 保持服务运行，终端会打印 `http://192.168.x.x:3000` 形式的地址。
2. 在其他设备浏览器打开该地址。
3. 如无法访问，放行 Windows 防火墙：

```bat
netsh advfirewall firewall add rule name="Daily Planner" dir=in action=allow protocol=TCP localport=3000
```

## 账号说明

- 新安装时没有预置账号，登录页只显示注册表单。
- 注册时密码留空会创建免密档案。
- 所有账号数据只保存在本机，不做云端同步或找回密码。
- 从旧版本升级时，如果检测到已有数据，会自动迁移到“默认用户”，不会删除旧数据。

## 自动排程规则

默认规则示例：

| 关键词 | 时长 | 时段 |
| --- | --- | --- |
| 会议 / 开会 | 60 分钟 | 上午 |
| 写作 / 报告 / 方案 / 文档 | 60-90 分钟 | 上午 |
| 学习 / 阅读 / 课程 | 60 分钟 | 下午 |
| 电话 | 20 分钟 | 下午 |
| 健身 / 跑步 / 运动 / 瑜伽 | 45 分钟 | 晚上 |
| 买菜 / 购物 / 家务 | 30 分钟 | 晚上 |

标题中出现数量词时优先按数量词估算；未匹配时按分类兜底。默认排程时段 09:00-22:00，午休 12:00-13:30 不会安排普通任务。可在“设置”页调整。

## 项目结构

```text
server.js                Express 服务与认证
lib/db.js                数据层：账号、任务、习惯、专注、复盘、统计
lib/scheduler.js         自动排程与时长解析
public/                  前端页面（原生 JS + CSS + PWA）
tests/                   Node 内置 test runner 测试
scripts/privacy-check.mjs 提交前隐私检查工具
SECURITY.md              安全与隐私说明
data/                    运行时生成的 SQLite 数据库（不入库）
```

## 安全说明

- 数据只保存在本机，不依赖云端服务。
- 密码使用 Node 内置 `crypto.scrypt` 哈希后存储。
- 本应用适合局域网或本机使用，不建议直接暴露到公网。
